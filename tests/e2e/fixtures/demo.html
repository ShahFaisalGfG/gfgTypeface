Reading should fit the reader

5 min read · Typography

Small type, tight lines and thin fonts make long articles hard work. A comfortable font at a comfortable size turns the same page into an easy read, without breaking the layout the site was built with.

اردو تحریر کے لیے نستعلیق خط سب سے خوبصورت لگتا ہے، چاہے صفحہ انگریزی میں ہی کیوں نہ ہو۔

Mixed pages work too: English sentences keep your main font while Urdu words such as خوش آمدید use the Urdu font you picked, in the same line.

Code samples like const size = 1.25; keep a monospace font of your choice.
